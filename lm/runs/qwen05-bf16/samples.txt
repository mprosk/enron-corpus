### 基本信息
1. **防火墙版本**：确保你的防火墙是最新版本。
2. **IP地址和端口**：检查当前连接的IP地址和端口号是否正确。
3. **系统日志**：查看系统日志文件以获取更多信息。

### 检查防火墙配置
1. **修改/删除规则**：检查防火墙规则是否正确配置，是否存在过时或错误的规则。
   - 打开防火墙配置文件：
     ```bash
     sudo systemctl stop sysv-irc
     ```
   - 修改防火墙规则：
     - **允许从所有IP访问**：
       ```bash
       sudo firewall-cmd --permanent --add-rich-rule='rule family=ipv4' \
       'proto=icmp' \
       'destination-port=25'
       ```
     - **允许所有远程主机访问**：
       ```bash
       sudo firewall-cmd --permanent --add-rich-rule='rule family=ipv4' \
       'proto=udp' \
       'destination-port=3306'
       ```

   - 使用`netstat`或`ss`命令检查当前系统
